
# input() function

Look up documentation on the 'input()' function
- how is the function described?  It is used to get input from the user for processing it - a prompting function for the user to return a value to
- what are the inputs? The user can input any data related to the prompt in the function 
- what is the output? The function then reads a line from input, converts it to a string (stripping any trailing newline), and returns that
- think about the description of the data and also the type
